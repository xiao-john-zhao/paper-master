# paper-master v0.4.5 下载安装使用指南

适用：Windows 10/11，64 位 Intel/AMD 电脑。发布日期：2026-10-27。

## 一、下载与打开应用

### 已下载仓库 ZIP 或免安装启动包

从 v0.4.5 起，仓库保留当前正式版完整 EXE。登录有权限的账号后，在仓库选择 **Code → Download ZIP**，或在 Release 下载 `paper-master-v0.4.5-portable-windows-x64.zip`。

1. 把 ZIP **完整解压**到本地文件夹，不在压缩软件内直接运行。
2. 双击根目录的 **启动paper-master.cmd**。
3. 也可以直接双击 `application/paper-master.exe`。无需 Node.js、Rust、Python 或编译步骤。
4. 此方式需要系统已安装 WebView2。缺少运行时时按下面的方法使用安装器。

启动脚本通过自己的所在位置找到程序，移动解压文件夹或从不同工作目录运行不需要改路径。仓库当前分支与 v0.4.5 及后续发布的 Source code ZIP 均包含应用；更早版本的 Source code ZIP 可能只有源码。

### 使用安装器（包含 WebView2 离线组件）

1. 打开 [Release 下载页](https://github.com/xiao-john-zhao/paper-master/releases/latest)。私有仓库只有所有者和受邀协作者能访问。
2. 下载 `paper-master_0.4.5_x64-setup.exe`，或下载 `paper-master-v0.4.5-windows-x64.zip` 并解压。
3. 双击 `_x64-setup.exe`，选择简体中文，按提示安装。
4. 从 Windows 开始菜单打开 paper-master。安装器分享 ZIP 是安装包，不应把它当成免安装包。

安装包包含 WebView2 离线安装程序；缺少 WebView2 时由安装器处理，已安装时复用现有运行时。系统权限或企业策略可能要求管理员协助。安装包未做付费代码签名；如 Windows 阻止运行，请先核对来源及 SHA-256，并按所在单位的软件管理要求处理。不要关闭系统安全防护。

### 核对应用和分发内容

`application/release.json` 和 `application/SHA256SUMS.txt` 记录正式版 EXE 的版本及校验值。Release 的 `SHA256SUMS.txt` 记录安装器和两种 ZIP 的校验值。PowerShell 校验示例：

```powershell
Get-FileHash .\application\paper-master.exe -Algorithm SHA256
Get-FileHash .\paper-master_0.4.5_x64-setup.exe -Algorithm SHA256
```

免安装 ZIP 只包含正式版应用、启动脚本、发布清单、中文说明、可选 LM Studio 安装入口和校验文件。安装器 ZIP 只包含安装器与说明/校验文件。二者均不包含个人论文、数据库、缓存、临时文件、API 密钥、模型或账号登录状态。

## 二、选择 AI 服务

### 方式 A：在本机使用 LM Studio

1. 双击分享包里的 `Install-LMStudio.cmd`。脚本通过 Windows 的 winget 下载并安装 `ElementLabs.LMStudio`；不可用时打开 [LM Studio 官方下载页](https://lmstudio.ai/download?os=windows)。这一步需要联网。
2. 打开 LM Studio，在应用中搜索并下载适合本机内存/显存的模型。模型文件通常较大，需要单独下载；安装 paper-master 不会自动下载模型。不要直接套用其他电脑的显存、上下文配置。
3. 在 LM Studio 的 Developer / Local Server 页面启动服务，确认地址为 `http://127.0.0.1:1234`。
4. 在 paper-master 的 Settings 中选择 **LM Studio**，Base URL 保持 `http://127.0.0.1:1234/v1`。
5. 点击“加载并测试”，选择模型，保存设置。分析可完全留在本机，联网开关可保持关闭。

首次配置可保留默认参数和“失败后自适应重试”。自行提高配置时，以本机实际容量为准。已加载模型的实际上下文由 LM Studio 决定；修改加载上下文后需要在 LM Studio 卸载并重新加载。paper-master 不会强制卸载你正在使用的模型。

熟悉命令行的用户也可用官方 [`lms get`](https://lmstudio.ai/docs/cli/local-models/get) 搜索下载模型；`lms` 是可选工具，不是 paper-master 启动条件。

### 方式 B：使用其他 AI API

1. 在 Settings → Provider 选择 **其他 API（OpenAI 兼容）**。
2. 填写服务方提供的 API 地址、API Key 和模型名称。地址需要包含服务要求的前缀，例如 `https://你的服务地址/v1`；应用在后面追加 `/chat/completions`。
3. 输出格式默认 **JSON Object**；服务支持严格 JSON Schema 时可切换。两种模式都要通过本机结构、中文和原文证据校验。
4. 仅当服务明确支持 `reasoning_effort` 时勾选对应选项。
5. 勾选联网授权并保存，再测试连接或分析。关闭联网并保存后，外部 API 请求会被阻止。

API 模型可以直接手填；某些服务没有 `/models` 列表接口，此时列表测试失败不代表分析接口不可用。使用 HTTPS；本机回环服务也允许 HTTP。密钥使用 Bearer 认证，不支持把密钥放入 URL 查询参数。API 地址和 LM Studio 本机地址分别保存。

本版本支持 OpenAI 兼容的 Chat Completions 协议。仅支持 Anthropic 原生 Messages、OpenAI Responses 等其他协议的地址，需要兼容网关，不能直接填入。不同服务的模型、格式及推理参数支持范围不同，错误会显示在详情中；本次发布没有替你调用付费服务进行实测。

启用在线分析会向所选服务发送有长度上限的论文材料，可能产生服务方费用。API Key 保存在本机应用数据库中，输入框默认遮挡；不写入论文 JSON 缓存、诊断日志或分享包。请勿向他人提供自己的应用数据库。

### 方式 C：Codex CLI 或演示模式

已有 Codex CLI 的用户可以选择 Codex，完成本机 `codex login` 并启用联网授权。Codex 的安装和登录不是普通用户运行 paper-master 的必要条件。Codex 联网关闭时沿用本机 LM Studio 回退行为。

只想查看界面，可选择 **Mock (development)**。它生成演示结果，不能作为真实论文分析；“补齐待分析”也不会使用演示模型。

## 三、导入、分析与编辑

1. 在资料库导入 PDF 或文件夹。原 PDF 保留原位置，不会被移动、覆盖或删除。
2. 默认首次导入后自动分析，任务在队列中串行运行；可在设置关闭自动分析。退出后，下次启动恢复未完成任务。
3. 在论文详情点击分析，可生成新版本；不同模型的历史结果继续保留。每个结果显示服务、模型和时间，历史缺失的型号会明确标注。
4. 通过“查看整理结果”选择需要修改的版本，点击 **编辑 AI 分析内容**。
5. 可编辑概览、研究问题、研究场景、核心方法、创新、贡献、结果、局限和关键词。创新、贡献、关键词每行一项。点击“保存编辑”后更新检索及本地论文缓存。
6. “恢复生成文字”恢复该版本最初生成的内容；修改其他版本不会覆盖当前版本。元数据仍从“编辑题名、作者与摘要”进入。

“本地归档摘录”只是从原文提取的材料，界面明确标为非模型。扫描件或无嵌入文字的 PDF 需要先 OCR，无法通过调高模型参数补出原文。

### 本地分析失败后的自适应处理

每篇首先以摘要、引言、结论等有界材料生成一份简短的整体语义基准，并保存原文引文，再尝试已保存配置的最高档位。

1. **高参数直接分析**：优先保留最多的章节材料和所设输出上限。
2. **较低参数直接分析**：失败后先降低额外推理强度，再将章节输入预算调整至原设置的 70%、45%、25%，最低 4000 字符；需要新加载模型时同步降低请求的上下文。
3. **完整分段阅读**：直接方案仍失败时，对全部可提取文字重叠分段，每段保留原文字符范围、发现和逐字引文；每段按容量调整参数，成功配置可在同篇后续段复用。不能跳过失败段。
4. **分层综合**：证据总量超过上下文时分组综合，校验引文仍来自原文、已有的研究问题/场景/方法/创新/贡献/结果/局限类别没有整类丢失，直至可以形成统一分析。不会把分段摘要简单拼接。
5. **语义复核**：用整体语义基准与抽样原文证据检查最终候选。基准可能不完整，原文优先；发现实质冲突或证据不足则继续回退，无法通过时保留失败原因。

第一个满足本阶段结构、中文、证据和语义一致性要求的方案才保存。取消、服务离线、模型不存在、无文字等情况不会无意义地循环重试。分段处理最多256段、每次综合最多16层，超过上限会明确失败，不会默默截掉剩余部分。

调整只作用于当前论文，下一篇重新从最高配置开始。最终分析输出上限不因截断而缩小；语义基准、证据笔记和复核采用较小的独立输出预算。详情可展开“处理方案与语义可信度复核”，查看基准、复核引文、分段范围、参数与覆盖量。人工修改后的文字会注明尚未重新复核。

“覆盖全部”仅指 PDF 已提取文字；扫描图片、无法提取的公式和图表并未因此自动识别。分段证据会被压缩，语义复核也是有界材料的启发式一致性检查，不能保证所有细节无遗漏、分析绝对正确或数学意义上的最优方案。请核对关键结论和数值。分段中间材料本次保存在任务内存中；若应用退出，持久队列会重跑该篇，不会把未完成的段落当作整篇结果恢复。

### 切换页面与后台任务（v0.4.4）

在应用运行期间，切换侧栏页面会保留已打开页面的输入、选择、检索结果、图谱视野和进行中操作。联网检索不会因切换到设置或其他页面而自动取消；返回后可继续查看同一任务的进度与结果。普通窗口失焦或切换到其他应用也不重置这些页面状态。

对比窗口右上角“×”和点击遮罩改为暂时收起，不会取消任务。通过侧栏“查看进行中的对比 / 查看上次对比”重新打开；未保存的对比编辑也会保留。只有明确点击“取消”才停止本次对比，取消后仍能返回查看状态并重试。

设置在初次读取、连接检查或保存时暂时禁用表单，避免迟到的读取结果覆盖新输入。未保存草稿仅保存在本次应用运行的内存中，不自动写入数据库、论文缓存、日志或云端；退出或重启应用前请先保存。持久论文分析队列的重启恢复行为保持不变；运行中切换页面和退出程序是不同操作。

## 四、查看关系图局部细节

进入“论文关系图”，选择关键词网络、论文网络或潜在同团队。

- **滚轮缩放**：以鼠标所在位置为中心查看局部；也可双击或点击 + / −，范围为 20%–1200%。
- **拖动空白处**：平移视野；重置恢复初始视野。
- **圈和字**：缩放重新计算节点及连线坐标，不整体放大图片。节点大小、文字大小有独立滑杆，连线点击区域保持可用。
- **查看细节**：放大至 180% 后展开完整标题并换行；选中节点也展开完整文字。点击“聚焦此节点”，或勾选“只看当前图中的直接关联”，排除其他节点干扰。
- **核对关系**：点击节点或连线，在右侧查看关联论文和依据，可直接进入论文详情。

图谱仍有最多 80 节点、240 条关系的可读性上限，底部会显示省略数量；局部筛选基于当前已显示图，不会凭空补齐被全局筛选省略的关系。可调节点数和门槛后刷新。SVG/PNG 导出是完整筛选图及图例，独立于当前相机视野。

共同关键词、署名和潜在团队关系不等于引用、同一作者身份或已确认课题组，须返回原文核实。

## 五、升级、备份和分享

升级前关闭 paper-master，备份 Diagnostics 中显示的应用数据目录及所选缓存目录，再运行新安装器。安装目录、EXE 名称和版本号不会改变同一 Windows 用户的应用数据位置。

默认数据位于 `%APPDATA%\app.papermaster.desktop\`。SQLite 保存论文、分析和设置；论文恢复缓存默认在该目录下 `library-cache\v1\`，也可在 Diagnostics 更换位置。目录名 v1 保持兼容，本次缓存文件格式为第 2 版，可读取第 1 版并保留成功参数，不要求搬迁目录。旧应用不一定能读取新格式，回退前请使用升级前的备份。

新电脑只安装软件时会建立自己的空资料库。迁移个人论文库应另外复制个人缓存及原 PDF，在新电脑读取搬运后的缓存，再重新关联变化的 PDF 路径。API Key 和登录状态需重新配置；不要把数据库当作公共分享文件。

分享应用时只发送 Release 中的安装器或 Windows ZIP；给对方私有仓库访问权限，或直接传递安装文件。无需分享开发源码和自己的论文数据。可选的 LM Studio 脚本会从网上安装外部软件，不会复制作者机器上的程序、模型或设置。

## 六、排错

| 现象 | 处理 |
| --- | --- |
| 没有模型 / 连接失败 | 确认 LM Studio 已下载模型、启动服务，地址为本机回环；再加载并测试 |
| 外部 API 无法连接 | 核对联网授权、地址前缀、密钥和模型；不支持 /models 时手动填模型后分析 |
| 输出格式不支持 | 按服务文档切换 JSON Object / JSON Schema，关闭不支持的 reasoning_effort |
| 所有自适应档位都失败 | 在 LM Studio 检查模型容量与运行状态，必要时选更适合该电脑的模型；不会伪造成功 |
| 只有摘录，没有 AI 分析 | 配置真实模型，然后单篇分析或点击“补齐待分析” |
| 缓存同步失败 | 在 Diagnostics 查看路径、空间和权限并重试；数据库中已保存结果仍保留 |
| PDF 移动后打不开 | 在详情重新关联文件，不要删除原 PDF |

本次验证包含前后端自动化测试和 Windows 安装器构建；未在另一台全新电脑或所有第三方 API 上做端到端验证。更多诊断方法见 [DEBUGGING.md](../DEBUGGING.md)。

## 七、开发者从源码构建

普通用户无需阅读本节。开发者需要 Node.js、项目固定版本 pnpm、Rust MSVC、Visual Studio C++ Build Tools。保持锁文件，不复制他人的 node_modules 或 target。

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm build
cargo test --locked --manifest-path src-tauri/Cargo.toml
pnpm tauri build --ci -- --locked
```

安装包输出到 `src-tauri\target\release\bundle\nsis\`。首次打包 WebView2 离线运行时需要联网。协议及安装行为参考 [Tauri 官方 Windows 安装文档](https://v2.tauri.app/distribute/windows-installer/)；JSON Object 的服务兼容示例可参考 [DeepSeek 官方 JSON 输出文档](https://api-docs.deepseek.com/guides/json_mode/)。
